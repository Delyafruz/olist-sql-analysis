# Olist E-Commerce SQL Analysis

Анализ данных бразильского интернет-магазина Olist с помощью PostgreSQL.
Датасет: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (Kaggle).

## Бизнес-вопросы

- Сколько всего заказов и как они распределены по статусам?
- Как меняется количество заказов и выручка по месяцам?
- Какая общая выручка магазина?
- (на день 2) Какая выручка по категориям товаров, топ-10 категорий, среднее время доставки?
- (на день 2) Какая доля заказов доставлена с опозданием?
- (на день 3) Как меняется выручка месяц к месяцу (рост в процентах)?

- Всего заказов: 99 441.

- Данные охватывают период примерно с сентября 2016 по октябрь 2018 (25 месяцев).

## Как запустить

1. Скачать датасет с Kaggle и распаковать CSV-файлы в папку `data/`.
2. Создать базу `olist` в PostgreSQL.
3. Установить зависимости: `pip install pandas sqlalchemy psycopg2-binary`.
4. Задать пароль: `$env:PGPASSWORD="ваш_пароль"`.
5. Запустить: `python load_data.py`.
6. Выполнить запросы из папки `sql/` в pgAdmin или любом SQL-клиенте.
